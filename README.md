# Fundamentos de Swift

## Objetivo
Ensinar os fundamentos de Swift a iniciantes, do zero até o primeiro app para iOS.

Ao final do guia, o estudante será capaz de programar e entender a linguagem Swift e de desenvolver seus primeiros aplicativos para iOS com SwiftUI.

## Público-alvo
Estudantes que nunca desenvolveram para iOS, incluindo quem está começando a programar agora. Não é preciso conhecer outra linguagem: cada conceito é explicado com exemplos curtos e exercícios.

## Pré-requisitos
- Noções básicas de lógica de programação (desejável, não obrigatório).
- Uma forma de rodar código Swift:
  - **Mac com Xcode** (gratuito na App Store) — necessário para criar apps iOS;
  - **iPad ou Mac com Swift Playgrounds**;
  - **Sem Mac:** Swift para Windows/Linux ou o SwiftFiddle, no navegador (só para praticar a linguagem).
- Git e uma conta no GitHub, para acompanhar o repositório.

## Como navegar
Siga a ordem numérica dos módulos: **01 → 02 → 03 → 04**.

1. Leia a **Introdução** e deixe o ambiente pronto para rodar código.
2. Estude os **Conceitos** testando cada exemplo no seu editor.
3. Resolva os **Exercícios** antes de abrir o gabarito.
4. Use as **Referências** para aprofundar e continuar estudando.

Cada módulo termina com um link para o próximo.
