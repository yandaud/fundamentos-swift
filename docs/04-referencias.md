# 04 — Referências

## Documentação oficial
- [The Swift Programming Language](https://docs.swift.org/swift-book/) — livro oficial da linguagem (em inglês).
- [Swift.org — Getting Started](https://www.swift.org/getting-started/) — primeiros passos e instalação.
- [Apple — SwiftUI Tutorials](https://developer.apple.com/tutorials/swiftui) — tutoriais guiados para montar apps.
- [Swift Playgrounds](https://www.apple.com/swift/playgrounds/) — app da Apple para aprender Swift no iPad e no Mac.

## Cursos gratuitos
- [100 Days of SwiftUI — Hacking with Swift](https://www.hackingwithswift.com/100/swiftui) — do zero ao app, uma aula por dia.
- [Stanford CS193p](https://cs193p.sites.stanford.edu/) — curso de desenvolvimento iOS com SwiftUI.

## Praticar sem Mac
- [SwiftFiddle](https://swiftfiddle.com/) — rode Swift direto no navegador.
- [Instalar Swift (Windows/Linux)](https://www.swift.org/install/) — compilador oficial.

## Comunidade
- [Swift Forums](https://forums.swift.org/) — fórum oficial da linguagem.

## Git e GitHub (usados neste projeto)
- [Pro Git, em português](https://git-scm.com/book/pt-br/v2) — livro gratuito sobre Git.
- [Conventional Commits](https://www.conventionalcommits.org/pt-br/v1.0.0/) — padrão das mensagens de commit.
- [GitHub Docs — Pull requests](https://docs.github.com/pt/pull-requests) — como abrir e revisar PRs.
